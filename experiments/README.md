# AI Experiments & Model Evaluation

This directory contains standalone experimentation datasets, evaluation notebooks, and benchmark scripts.

## Scope & Guidelines
- **Autonomous Coding Agent Role:** Responsible exclusively for the software system, infrastructure, APIs, and business logic.
- **Model Development & Fine-Tuning:** Handled separately using Google Colab or high-VRAM dedicated research environments.
- **Directories:**
  - `experiments/router/`: Query classification datasets, intent routing benchmarks, and confusion matrices.
  - `experiments/rag/`: Retrieval chunking experiments, dense vs. sparse retrieval benchmarks, and reranker evaluation.
  - `experiments/vision/`: Engineering drawing OCR evaluation, symbol detection notebooks, and visual QA accuracy logs.
